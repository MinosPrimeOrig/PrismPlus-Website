Roadmap

The planned order of work. It is a sequence, not a schedule: no dates or release versions are promised.

  1. Done

    Phase 0 — Foundation

    Project skeleton, provenance documents and a build check. The build and all 24 of 24 tests passed (tag plus-phase-0).

  2. In progress

    Servers MVP

    First working version of the Local Server Manager. Step 1 (server profile and registry) is written; tests are pending.

  3. Planned

    More server cores and instance link

    Additional server cores, and linking a server to an existing Java instance without modifying that instance.

  4. Planned

    Bedrock client

    Detect and launch an installed Bedrock Edition with an OS-appropriate mechanism, as a separate module.

  5. Planned

    Bedrock Dedicated Server

    Run Bedrock Dedicated Server from the Local Server Manager, where the platform allows it.

  6. Planned

    Guides

    Detailed BUILD, DEPENDENCIES, TROUBLESHOOTING and TESTING guides.

  7. Later

    Deferred modules

    Sync, plugins and sandbox stay on the roadmap but are not scheduled.

Priorities can change as research and testing show what is feasible.
