Early development

A Minecraft launcher built on Prism.

Prism+ is a community-driven launcher based on Prism Launcher. It keeps the Prism you know and adds a Local Server Manager and a Bedrock module as separate, native-feeling modules.

DownloadExplore features

Why Prism+

Prism at the core

Proven instance management stays. We extend Prism instead of replacing it.

Modular by design

Server Manager and Bedrock live in their own modules, separate from Java launch logic.

Safe by default

Rollback before risky changes. Your instances and data are never altered without you.
