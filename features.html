Features

What Prism+ keeps from Prism, and what it adds. Status labels show where each item stands today.

Base

Prism foundation

Instances, accounts, mods and the familiar Prism UX stay intact.

In development

Local Server Manager

Create and run local Java or Bedrock servers: version and core choice, RAM, properties, console, logs, files, backups.

Planned

Server and instance link

Create a server from an existing Java instance and manage client and server separately. The original instance is never modified.

Planned

Bedrock module

Detect installed Bedrock, check platform compatibility, show the version and launch it with an OS-appropriate mechanism, never via the Java runtime.

Planned

Nivora-inspired ideas

Selected ideas from Nivora Launcher, re-implemented independently on the Prism stack with licenses respected.

Principle

Rollback and data safety

Rollback ability before risky changes; user data and instances are preserved.

None of this ships as a stub: items arrive in releases as they become ready.
