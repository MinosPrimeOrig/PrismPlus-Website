Security policy

How to report a problem responsibly, and how to stay safe when using Prism+.

Scope

This policy covers the Prism+ launcher once it is released, and this website.

Supported versions

There are no public releases yet, so no version receives security fixes at the moment. When releases exist, this page will state which ones are supported.

Reporting a vulnerability

Please do not report security issues in public issues, pull requests or chats.

A private reporting channel will be published on this page before the first release. Until then, keep the details to yourself and do not disclose them publicly.

What to include

  • Affected version or commit, and platform
  • Steps to reproduce
  • What an attacker could do (impact)
  • A suggested fix, if you have one

Responsible disclosure

Please give us a reasonable amount of time to fix a problem before you publish details. We are happy to credit reporters who want to be named.

Staying safe

  • Download Prism+ only from the Download page of this site or the project's GitHub Releases.
  • Verify the SHA-256 checksum of every file you download.
  • Treat builds from other sources as unofficial and untrusted.
