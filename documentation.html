Overview

Prism+ is a Minecraft launcher based on Prism Launcher. It keeps Prism's proven features and look, and adds new capabilities as separate modules.

Development stages

Work moves through five stages in order:

  1. Research
  2. Architecture
  3. Implementation
  4. Testing
  5. Documentation

Large-scale changes start only after research is finished.

Architecture principles

  • Prism stays the base; proven features are kept.
  • C++ and Qt only, following Prism's code style.
  • New modules are standalone: their own registries and data directories, not BaseInstance subclasses.
  • Bedrock and Server Manager stay separate from Java launch logic.
  • Maximum compatibility with upstream Prism, and rollback ability before risky changes.

Building

Prism+ uses the same C++, Qt and CMake toolchain as Prism Launcher.

Detailed guides (BUILD, DEPENDENCIES, TROUBLESHOOTING and TESTING) are planned and will be linked here.
