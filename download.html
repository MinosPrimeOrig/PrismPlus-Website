Verify your download

Every release lists a SHA-256 checksum for each file. After downloading, compute the checksum yourself and compare it with the listed value. If they differ, delete the file and do not run it.

Windows (PowerShell)

Get-FileHash .\FILENAME -Algorithm SHA256

Linux

sha256sum FILENAME

macOS

shasum -a 256 FILENAME

A matching checksum shows the file arrived intact. It proves where the file came from only if you got the checksum from this site or the project's GitHub Releases.
