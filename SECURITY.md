# Security Policy

Prism+ has no public releases yet, so no version currently receives security fixes.

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or chats.

A private reporting channel will be published in this file and on the website (`security.html`) before the first release. Until then, please keep details to yourself and do not disclose them publicly.

When you report, include the affected version or commit and platform, steps to reproduce, the possible impact, and a suggested fix if you have one.

## Responsible disclosure

Please give the maintainers a reasonable amount of time to fix a problem before publishing details.

Full policy: `security.html`.
