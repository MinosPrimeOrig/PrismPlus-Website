FAQ

Short answers about Prism+. If something is not covered, it is probably not decided yet.

What is Prism+?

A community-driven Minecraft launcher based on Prism Launcher. It keeps Prism's proven features and adds a Local Server Manager and a Bedrock module as separate modules.

Can I download it now?

Not yet: there is no public release. When one exists, its files and SHA-256 checksums will be listed on the Download page.

Download
Is it just a renamed Prism Launcher?

No. Prism is the base, but Prism+ adds its own modules with their own data and registries, and its own identity. Adapted ideas are re-implemented independently and licenses are respected.

Will it change my existing instances?

It is designed not to. Instances are never altered without your action, and rollback ability is required before risky changes. Compatibility details will be documented with the first release.

Will Bedrock Edition be supported?

A separate Bedrock module is planned: it does not exist yet and is at the research stage. Bedrock will never be launched through the Java runtime.

What is the Local Server Manager?

A module for creating and running local Java or Bedrock servers: version and core choice, RAM, properties, console, logs, files and backups. It is in development; not everything listed exists yet.
